# 🏡 House Price Prediction System

An AI-powered House Price Prediction web application built using **Python**, **Machine Learning**, and **Streamlit**. The application predicts house prices based on property features using trained regression models and provides interactive analytics through a modern user interface.

---

## 📌 Project Overview

This project uses the California Housing Dataset to train multiple machine learning regression models. The best-performing model is automatically selected and used for real-time house price prediction through an interactive Streamlit web application.

---

## ✨ Features

- 🤖 Machine Learning based house price prediction

- 📊 Interactive Analytics Dashboard

- 📈 Model Performance Comparison

- ⚡ Fast real-time prediction

- 🎨 Modern and Responsive Streamlit UI

## 📊 Machine Learning Models Used

The following regression models were trained and compared:

- Linear Regression

- Decision Tree Regressor

- Random Forest Regressor

- Gradient Boosting Regressor

### 🏆 Best Model

**Random Forest Regressor**

Performance:

- **R² Score:** 0.8038

- **MAE:** 0.3278

- **RMSE:** 0.5065

## 🚀 Installation

Clone the repository

```bash

git clone [https://github.com/Raghavverma06/House-Price-Prediction-System.git](https://github.com/Raghavverma06/House-Price-Prediction-System.git)

```

Go to project folder

```bash

cd House-Price-Prediction-System

```

Install dependencies

```bash

pip install -r requirements.txt

```

Run the application

```bash

streamlit run [app.py](http://app.py)

```
